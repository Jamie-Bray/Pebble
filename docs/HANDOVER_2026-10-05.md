## 4. AI photo steps: read before touching anything AI-related

**Agreed shape (Jamie's own design):**

- Personal Premium only.
- One routine at a time can have AI on; up to five photo steps in it.
- Switching it on shows a short, friendly sheet with **one unticked tick box**:
  "I'm happy for photos from this routine to be sent to Anthropic to be
  described."
- The photo is sent to the provider, which returns one or two sentences saying
  what is visible. It never gives a verdict ("locked", "off", "safe"); the
  server discards any description containing one.
- A description never completes, blocks or fails a step.
- Completion emails: when AI is switched on, ask whether to add descriptions to
  the email, with neither answer pre-selected. Photos are never emailed.
- Built **switched off by default**. Nothing is deployed. No real provider call
  has been made.

**Provider:** Anthropic, model `claude-haiku-4-5`, about $1.50 per 1,000 photos.
Google is ruled out because its developer terms exclude apps open to under-18s.

pushed the Edge Function `describe-proof-photo`, migration `021`, and the email
changes. The app side, tests and documents were still to come.
